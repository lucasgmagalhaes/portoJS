# Playground

Edit the code and press **Run**. The library is available as `portojs`, and `console.log` prints below. Everything runs in your browser; nothing is sent anywhere.

<ClientOnly>
  <Playground />
</ClientOnly>

A `ManualClock` is used in most examples so results are deterministic. In a real game you simply omit `clock`, and the real time is used. Everything is imported from `portojs`; in a plain script that is the `portojs` object shown above.
