# Tutorials

Four guided paths, from the first line of code to a game with sprites and physics. Every code listing on these pages is a real file in the repository, run by the automated tests, so what you read is what works.

| Tutorial                                     | You build                              | You learn                                           |
| -------------------------------------------- | -------------------------------------- | --------------------------------------------------- |
| [Hello, game](/tutorials/hello-game)         | A player with health                   | Game, components, the fixed loop, saves             |
| [Your first idle game](/tutorials/idle-game) | Miners, mines, an upgrade and prestige | Resources, generators, formatting, offline progress |
| [A sprite game](/tutorials/sprite-game)      | Ten thousand moving sprites            | The ECS, batching and the WebGPU/WebGL2 renderer    |
| [A bouncing ball](/tutorials/bouncing-ball)  | A ball that falls and bounces          | Physics bodies and collision events                 |

Each tutorial assumes you can read TypeScript and have Node and pnpm. Start with the first one: the others build on its ideas.

When you want to look something up rather than follow a path, use the [catalogue](/catalogue) or the [API reference](/api/).
