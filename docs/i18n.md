# Translations

`@portojs/i18n` translates your game: message tables per language, plurals that follow each language's rules, and numbers and dates formatted the way the player expects.

```
pnpm add @portojs/i18n
```

## Messages

```ts
import { I18n } from '@portojs/i18n';

const i18n = new I18n({
  locale: 'pt-BR',
  fallback: 'en',
  messages: {
    en: {
      title: 'Idle Miner',
      shop: { buy: 'Buy', owned: '{n, plural, =0 {None owned} one {# owned} other {# owned}}' },
      welcome: 'Welcome back, {name}!',
    },
    'pt-BR': { shop: { buy: 'Comprar' }, welcome: 'Bem-vindo de volta, {name}!' },
  },
});

i18n.t('shop.buy'); // "Comprar"
i18n.t('welcome', { name: 'Ana' }); // "Bem-vindo de volta, Ana!"
i18n.t('title'); // not in pt-BR: the English "Idle Miner"
```

A key is looked up in the current locale (`pt-BR`), then its language (`pt`), then the fallback and its language. A key found nowhere is returned as it is, so gaps are visible; pass `onMissing` to log them or to show something else.

## Placeholders, plurals and select

The message syntax is a subset of ICU MessageFormat:

| Syntax                                                | Result                                                                                                                      |
| ----------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `{name}`                                              | The parameter. Numbers are formatted for the locale (`1,234.5` or `1.234,5`).                                               |
| `{n, plural, =0 {none} one {# item} other {# items}}` | A branch by the language's plural rules (`zero`, `one`, `two`, `few`, `many`, `other`) or an exact `=n`. `#` is the number. |
| `{kind, select, boss {The boss} other {An enemy}}`    | A branch by the parameter's value.                                                                                          |
| `'{'` and `'}'`                                       | Literal braces. `''` is an apostrophe.                                                                                      |

Languages with more plural forms work without extra code (Russian has `one`, `few` and `many`). A plural or select without an `other` branch throws when nothing matches. A placeholder with no parameter stays as written.

## Numbers, dates and big numbers

```ts
i18n.number(1234.5); // "1.234,5"
i18n.date(new Date(), { dateStyle: 'long' });
i18n.big('1.5e9'); // "1,5 bi" in Portuguese, "1.5B" in English
```

`big` uses the locale's decimal separator and, for Portuguese, the Portuguese suffixes. Anything you pass in the options wins.

## Changing language

```ts
i18n.changed.addListener(({ to }) => redrawTexts(to));
i18n.locale = 'es';
```

Add a `Localization` component to keep the choice in the save, and `detectLocale` to start from the player's browser settings:

```ts
import { Localization, detectLocale } from '@portojs/i18n';

const supported = ['en', 'pt-BR', 'es'];
const locale = detectLocale(supported, navigator.languages, 'en');
const l10n = game.createObject('Localization').addComponent(Localization, { locale, messages });
```

On load the saved language replaces the detected one; after `game.reset()` the starting one comes back.
