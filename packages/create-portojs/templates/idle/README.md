# {{name}}

An idle game built with [PortoJS](https://github.com/lucasgmagalhaes/portojs): a resource, a
generator, offline progress, a "welcome back" message and autosave with backups.

```
npm install
npm run dev     # start the dev server
npm run build   # type-check and build to dist/
```

Everything is in `src/main.ts`. Next steps: add `Upgrade`, `Achievement` and `Prestige`
components (see the [idle guide](https://github.com/lucasgmagalhaes/portojs/blob/main/docs/components.md)),
and use the [balancing simulator](https://github.com/lucasgmagalhaes/portojs/blob/main/docs/balancing-and-devtools.md)
to tune the numbers.
