# {{name}}

A 2D sprite game built with [PortoJS](https://github.com/lucasgmagalhaes/portojs): an ECS world,
a batched WebGPU renderer (WebGL2 fallback), a screen-fitting viewport and a seeded random
generator.

```
npm install
npm run dev     # start the dev server
npm run build   # type-check and build to dist/
```

Everything is in `src/main.ts`. Click or tap to add sprites. See the
[ECS and rendering guide](https://github.com/lucasgmagalhaes/portojs/blob/main/docs/ecs-and-render.md)
for atlases, animation, text and sorting layers.
