# {{name}}

A [PortoJS](https://github.com/lucasgmagalhaes/portojs) game.

```
npm install
npm run dev     # start the dev server
npm run build   # type-check and build to dist/
```

`src/main.ts` has a `Game` with one component. Components are saved and restored by
`game.save()` and `game.load()`, see the [saves guide](https://github.com/lucasgmagalhaes/portojs/blob/main/docs/saves-and-migrations.md).
